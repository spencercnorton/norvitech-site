# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub:
**[Report a vulnerability](https://github.com/spencercnorton/norvitech-site/security/advisories/new)**.
Do not open a public issue, and do not include real credentials or personal paths in the report — a description and a minimal reproduction
are enough.

There is no e-mail address for security reports; the advisory form is the
only channel, and it is the one that is monitored. You will get an
acknowledgement within a week. Fixes ship as a tagged release; the advisory
is published once the release is out, and credits you unless you ask
otherwise.

## Supported versions

Only the latest tagged release is supported — it is what GitHub Pages serves.

## Scope

In scope: this repository's code and the artefacts it ships.
Out of scope: the products the site links to — each has its own advisory
form, linked from its README — and GitHub Pages itself.

## What this site does with credentials and data

Nothing. It is plain HTML and CSS served by GitHub Pages: no scripts, no
cookies, no analytics, no forms, no credentials. The only requests a visitor's
browser makes are to this site and, when they click a link, to GitHub or the
payment provider behind the donate link.
