Open-source apps for the Linux desktop and the self-hosted stack.

Small tools, one developer. No telemetry, no accounts, no hosted service; each README says exactly what leaves the machine, and each release is a tag you can read end to end.

  • Helios

    The desktop that sees everything your coding agents do.

    A native GTK4/libadwaita workbench for Claude Code, OpenAI Codex and OpenRouter models. Every session in one window, with permissions, budgets and the plan you agreed to where you can see them.

    MITAPT · Ubuntu 26.04GTK4 · Python
    OverviewGitHub

  • BitAgent

    A self-hosted BitTorrent DHT crawler and indexer built for the *arr stack.

    It crawls the DHT into Postgres, classifies what it finds, serves it over Torznab — and watches what your *arrs actually keep, feeding that back into what it indexes.

    MITDocker ComposeGo · Python · Postgres
    OverviewGitHub

  • XNote

    Sticky notes that stay on your desktop, and stay yours.

    A GTK4 descendant of Xpad for GNOME on Wayland: each note its own window, saved as you type, with optional encrypted backup to Dropbox or any rclone remote.

    GPL-3.0-or-laterAPT · Ubuntu 26.04GTK4 · C
    OverviewGitHub

  • XNote Placement

    Puts every XNote sticky note back where you left it.

    Wayland forbids an app from placing its own windows, so this GNOME Shell extension does it from the compositor side — position, monitor and workspace, on every login. Nothing to configure.

    GPL-3.0-or-laterAPT · Ubuntu 26.04GNOME Shell · JavaScript
    OverviewGitHub

  • SnipSnap

    Screenshot any region of any monitor on GNOME Wayland, with no permission dialog.

    The selection is drawn inside the compositor by a Shell extension, so one drag can cross monitors and there is no portal prompt. A full annotate-and-copy editor comes with it.

    GPL-3.0-or-laterAPT · Ubuntu 26.04Qt 6 · C++
    OverviewGitHub

  • NorviOS

    The NorviTech look for Ubuntu 26.04, from the boot splash to the window glass.

    Boot splash, login screen and About logo rebranded, and GTK windows turned to frosted glass, all through Ubuntu's own override points. One command removes it.

    GPL-3.0-or-laterFrom source · Ubuntu 26.04GNOME 50 · Shell · CSS
    OverviewGitHub
