Suite / Road Track

Road Track

What every car in the garage really costs, on top of LubeLogger.

A running-cost dashboard, a finance tab and printable reports for the self-hosted LubeLogger vehicle tracker, added over its published image without forking it.

Install with Docker ComposeSource on GitHub

The vehicle dashboard, on demonstration data. LubeLogger keeps the records; Road Track turns them into what each car costs to own — per month, per mile, by system and including the loan. It runs as LubeLogger's own container image plus a layer of browser-side files, so your existing data stays exactly where it is.

What it does

What a car costs, not what it burns

Running cost per month and per mile, spend by category and by system, the biggest expenses and the distance driven. It reads sensibly for a garage that logs no fuel at all, where LubeLogger's own dashboard reports zero miles.

From the day you bought it

Give a vehicle its purchase date and the odometer that day, and the previous owner's receipts and miles drop out of your cost per mile. Odometer readings are cleaned of mis-keyed and out-of-order values first.

A Finance tab for the car itself

Price, deposit, rate and term give a payment schedule that ends at exactly zero; typed valuations or per-model depreciation curves draw what it has been worth since. One toggle folds it all into the dashboard's totals.

Named, printable reports

Routine maintenance, full records and a cost summary, chosen by name instead of a column picker, with a toggle that leaves the prices off a history meant for a buyer or a mechanic.

Sharing you can see

A Collaborators tab on every vehicle, and for administrators an Access grid of who sees which car, inherited access included, changed with a checkbox through LubeLogger's own rules.

Finished, not configured

The theme in light and dark, an installable web app and phone layouts come in the image; the only settings are LubeLogger's, plus an optional Add a receipt button for an instance that files receipts from Telegram or e-mail.

Install

Docker Compose

Download docker-compose.example.yml from the repository as docker-compose.yml and run docker compose up -d; the image is ghcr.io/spencercnorton/roadtrack for amd64 and arm64. Turn on sign-in before anyone else can reach it. Commands in the README.

Already running LubeLogger

Change your service's image to Road Track's and keep its volumes; nothing in your data changes, and switching back is the same edit in reverse. Each release names the LubeLogger version it is built on.

Where your data lives

Everything stays in LubeLogger's own data volume, including the purchase, loan and valuation fields Road Track adds. Road Track stores nothing of its own, its pages talk only to the instance that serves them, and there is no telemetry; nothing leaves the machine unless someone presses a receipt link. The README table lists every path.
