# Homepage media

- `bitagent-dashboard.png`: the public BitAgent demonstration dashboard, from `ui/docs/screenshots/dashboard.png` at https://github.com/spencercnorton/bitagent. Its data is fictional.
- `helios-dark.mp4`, `xnote.mp4`, `snipsnap.mp4` and their posters: transcoded from the already-reviewed animated PNGs in `assets/spotlight/`, at 12 fps with no audio. The posters preserve the original first frame. MP4 gives these recordings playback controls and a reduced-motion fallback.
- NorviOS and XNote Placement stills use the existing reviewed spotlight images.
- Indigo uses the recording and poster from the stable 2.0.1 product page.

These are actual product demonstrations. NorviOS previews include companion extensions still in development; the homepage labels that limitation.
