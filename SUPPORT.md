# Support

- **Something is broken** — [open a bug report](https://github.com/spencercnorton/norvitech-site/issues/new/choose).
- **A question, or an idea** — [Discussions](https://github.com/spencercnorton/norvitech-site/discussions).
- **A security problem** — [private vulnerability reporting](https://github.com/spencercnorton/norvitech-site/security/advisories/new), never a public issue. See [SECURITY.md](SECURITY.md).
- **A problem with one of the apps** — use that app's own repository; every card on the site links to it.

This is one developer's project, maintained in the open; there is no
support contract and no e-mail address. Issues are answered as time allows,
and the newest tagged release is the only one that gets fixes.

If one of the NorviTech apps saves you time, you can [support its development](https://buy.stripe.com/8x26oH2U44f65TRe574wM04).

This repository is the source of [norvitech.com](https://norvitech.com), the front door of the NorviTech Suite.
